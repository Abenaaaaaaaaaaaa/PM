# 项目管理系统

四层嵌套的项目管理工具：客户 → 项目 → 环节 → 任务。纯前端单页应用，数据存 localStorage，可通过 GitHub Gist 跨设备同步。

## 目录结构

```
/
├── index.html          # 当前版本（v2.1）入口，GitHub Pages 直接访问
├── app.js              # 当前版本逻辑
├── style.css           # 当前版本样式
├── v1.0/               # v1.0 归档快照（可独立打开）
├── v2.0/               # v2.0 归档快照（可独立打开）
├── v2.1/               # v2.1 归档快照，与根目录内容完全一致
└── docs/               # PRD 与需求记录
    ├── PRD-项目管理系统v1.0.docx
    ├── PRD-项目管理系统v2.0.docx
    └── 项目管理系统-需求与优化记录.xlsx
```

## 版本对照

| 版本 | 代码位置 | 说明 |
|---|---|---|
| v1.0 | `v1.0/` | 初版，表格 + 日历 + 归档三视图，四层结构 |
| v2.0 | `v2.0/` | 重构版，新增侧边栏树、甘特/日历泳道、任务条拖拽 |
| v2.1 | 仓库根目录 + `v2.1/` | 当前线上版本，在 2.0 基础上修复日历泳道遮挡、优化移动端；两处内容完全一致 |

各版本目录内的 `index.html` 引用同目录的 `app.js` / `style.css`，直接在浏览器打开即可运行，互不干扰。

## 本地预览

```bash
python3 -m http.server 8000
# 当前版本：http://localhost:8000/
# v1.0：    http://localhost:8000/v1.0/
# v2.0：    http://localhost:8000/v2.0/
# v2.1：    http://localhost:8000/v2.1/
```
